情報工学の学び

情報工学を基盤に、組込みシステム、映像メディア処理、プログラミングを幅広く学び、技術を身につけています。仕組みを理解するだけでなく、課題を整理し、設計・実装・動作確認を通して形にする力を磨いています。

組込みシステムの技術

ソフトウェアとハードウェアを結びつけ、機器の動作を制御する組込み技術を習得しています。入力された情報を処理し、その結果を機器の動作につなげる一連の流れを理解し、限られたメモリや処理能力、応答時間を意識してプログラムを組み立てます。機能の実現に加えて、安定した動作や効率を考えながら設計・実装に取り組みます。

映像メディア処理の技術

画像や映像をデジタルデータとして扱い、目的に応じて加工・解析する技術を習得しています。画素や色の表現、フレームの連続による動きの表現を踏まえ、映像から必要な情報を取り出す処理や、見やすく伝わりやすい表現につなげる処理に取り組みます。画質と処理速度のバランスを意識し、データの特徴に合った処理方法を考えることを大切にしています。

幅広いプログラミング言語の習得

Go、Python、Java、C++、Kotlinなど、多くのプログラミング言語を習得し、それぞれの特性や得意な用途を踏まえて活用しています。言語ごとの文法に加え、データ構造、アルゴリズム、処理の分割といった共通する考え方を理解し、課題に応じた実装につなげています。組込み制御、メディア処理、Web制作など、目的や実行環境に合わせて言語を選び、読みやすさや保守のしやすさにも配慮して開発します。

教職課程

情報工学の専門科目と並行して、教職課程を履修しています。大学での学びの柱の一つです。

ポートフォリオサイト

自己紹介・学業・制作物をまとめた個人サイト。水族館をイメージした背景と、スクロールに合わせた動きを取り入れています。

HTML / CSS / JavaScript

デザイン

深い青をベースに、魚や泡、光がゆっくり動く水中の雰囲気を表現。大きな見出しと、左右交互に並ぶ角丸カードで情報をまとめています。

動きと操作

  • 左右に開くオープニング
  • スクロールに合わせて現れるカード
  • スクロールに連動して移動・回転する四角形
  • 背景アニメーションの一時停止・再開
  • スマートフォン表示と、動きを減らす端末設定への対応

構成

HTMLでページの構造、CSSでデザインと水中の演出、JavaScriptでスクロール連動や動きの切り替えを実装しています。
